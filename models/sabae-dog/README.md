# 鯖江ドッグ

福井県鯖江市のB級グルメ「鯖江ドッグ」の3Dモデルです。
## モデルの種類

| 種類 | フォルダ | 特徴 |
| --- | --- | --- |
| 高品質版 | [high-quality](high-quality/) | 形状や表面の細部を重視したモデル |
| ローポリ版 | [low-poly](low-poly/) | ポリゴン数を抑えたモデル |

## 制作方法

Tripoの有料プランで生成
