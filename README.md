# free-3d-models

無料で使える3Dモデルを公開するリポジトリです。ゲーム、映像、Web、VR・ARなど、個人・商用の制作に利用できます。

## 制作方法

Scaniverseなどを使用して、実物を撮影・スキャンして制作したモデルを含みます。
Tripoの有料プランなど、AIツールを使用して制作したモデルを含みます。
実物を題材にしたモデルも、形状・寸法・色を正確に再現するものではありません。
